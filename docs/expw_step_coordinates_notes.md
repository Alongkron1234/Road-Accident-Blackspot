# `expw_step_coordinates.csv` — เกณฑ์ที่ใช้เลือกพิกัด (Issue 07 step 4)

EXAT ไม่มีพิกัด lat/lng มาให้เลย มีแค่ `expw_step` (ชื่อทางด่วน) เป็น text ตามที่บันทึกไว้ใน
`docs/api_notes.md` — seed นี้ map ชื่อทางด่วนแต่ละสาย ไปยัง **พิกัดตัวแทน 1 จุดต่อสาย**
(ไม่ใช่พิกัดจุดเกิดเหตุจริง) เพื่อให้ EXAT เข้าร่วม pipeline ได้ แม้ความละเอียดจะหยาบกว่า ARMS มาก

รายชื่อ `expw_step` ทั้งหมดดึงมาจากข้อมูลจริงใน `raw_exat` (query `DISTINCT expw_step` ตรงจาก
Postgres ไม่ได้เดาจาก sample file) ได้ 9 ชื่อ
